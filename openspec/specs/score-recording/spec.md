## Requirements

### Requirement: 进行中对局的分数录入权限
系统 SHALL 允许成员修改本人在进行中对局的结算积分，并允许记分组管理员代填或修改同组成员的结算积分。系统 MUST 在服务端根据当前调用者身份及分数记录所属记分组进行授权，不得信任客户端传入的用户身份或记分组身份。

#### Scenario: 成员填写本人分数
- **WHEN** 对局状态为 `active`，且当前用户是分数记录所属成员
- **THEN** 系统保存该成员提交的结算积分

#### Scenario: 管理员代填成员分数
- **WHEN** 对局状态为 `active`，且当前用户是分数记录所属记分组的管理员
- **THEN** 系统允许管理员保存该成员的结算积分
- **THEN** 录入页显示正在代填的成员昵称

#### Scenario: 非本人且非管理员尝试修改
- **WHEN** 当前用户既不是分数记录所属成员，也不是分数记录所属记分组的管理员
- **THEN** 系统拒绝保存
- **THEN** 录入页不得将该用户显示为管理员代填状态

#### Scenario: 对局结束后尝试修改
- **WHEN** 对局状态不是 `active`
- **THEN** 系统拒绝本人和管理员修改分数

#### Scenario: 冷启动进入录入页
- **WHEN** 录入页加载时当前用户身份尚未写入应用全局状态
- **THEN** 系统先恢复当前用户身份，再判断本人、管理员及代填状态

#### Scenario: 页面参数中的记分组与分数记录不一致
- **WHEN** 页面参数中的记分组 ID 与分数记录所属记分组不一致
- **THEN** 系统以分数记录中的记分组 ID 作为权限及规则查询依据
